## Overview

A modern, high-energy static website for **Hungry Humans Unlimited Wings** — a casual dining restaurant specializing in unlimited chicken wings and samgyeopsal. The brief called for an energetic, appetizing design that works perfectly on mobile since most customers check the menu on their phones.

### Design Direction

- **Color palette**: Vibrant yellow gradient, stark black, and white with red spicy item accents
- **Typography**: Bold industrial display font for headings, clean sans-serif for menu readability
- **Vibe**: Street-food energy, youthful, casual dining

### Key Sections Built

1. **Hero** — Full-bleed headline with unlimited wings offer callout and CTA buttons
2. **House Rules Banner** — High-contrast strip with leftover policy (no sharing, ₱30 leftover fee)
3. **18 Signature Sauces Grid** — Visual sauce catalog with spicy/bestseller badges
4. **Ala Carte & Party Wings Pricing** — Clean card pricing table by piece count
5. **Group Meals (GM1–GM4)** — Value deal highlights with pax count badges
6. **Footer** — Location, hours, and social links

### Tech Stack

- **Framework**: Astro (zero-JS static output)
- **Styling**: Tailwind CSS v4
- **Deployment**: Vercel Edge Network ([hungry-humans.vercel.app](https://hungry-humans.vercel.app/))
